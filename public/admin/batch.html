分析全站內容中…

選既有案例＝把照片加到那個案例後面；選「新增」＝建立新案例。

手機可直接從相簿多選。照片會自動縮小到 1600px、壓縮後再上傳，不用先處理。第一張會當封面。

做法：在 Excel 或 Google 試算表照範本欄位填好 → 全選複製 → 貼到下面。也可以上傳 .csv 檔。

照片檔名＝案例名稱＋編號，例如「北屯30年透天老屋翻新-01.jpg」。案例名稱可用：標題「｜」前面那段、完整標題、或 CSV 的「照片名稱」欄（標題太長時建議填短名，例：北屯透天-01.jpg）。編號決定照片順序，第 1 張當封面。

照片可以先匯入文字，之後再用「① 多張照片上架」選擇該案例補上照片。

如何把網站交給別人？（3 步驟）
  1. 請新擁有者註冊 GitHub 帳號，並把帳號名稱給你。
  2. 按下方按鈕到 GitHub，拉到最下方紅色區塊按 Transfer ownership，輸入新擁有者帳號。新擁有者在 Email 按接受。
  3. 回到這一頁，系統會自動偵測網站已轉移，按「一鍵更新設定」就完成。
