## 公仔本體

| 款式 | 價格 | 說明 |
|---|---|---|
| 個人公仔 | NT$2,380 | 一尊，高約 15 公分 |
| 畢業、運動公仔 | NT$2,380 | 個人公仔的畢業、球衣造型 |
| 軍警公仔 | NT$2,380 起 | 獎盃款另計，請看線上商店或 LINE 詢問 |
| 獎盃公仔 | NT$2,880 | 公仔做在獎盃底座上 |
| 情侶公仔 | NT$4,760 | 兩尊一組，贈底座 |
| 結婚公仔 | NT$4,760 | 新郎新娘一組 |
| 25 公分大公仔 | NT$5,500 | 加大尺寸，高約 25 公分 |
| 團體公仔 | 依人數報價 | 請 LINE 傳照片詢問 |

## 加購

| 項目 | 價格 |
|---|---|
| 固定款場景（波麗，不能客製） | NT$750 |
| 客製化（磁磚轉印）場景 | NT$1,600 |
| 個人公仔專用壓克力盒 | NT$500 |
| 獎盃公仔專用壓克力盒 | NT$650 |
| 場景專用壓克力盒 | NT$700 |
| 矽晶片字牌（約 20 字，金或銀） | NT$180 |

## 運費和付款

- 黑貓宅急便寄送，不論數量，本島 NT$120、離島 NT$220
- 付款方式：ATM 轉帳、超商代碼、信用卡，都不另收手續費

價格以線上商店和 LINE 報價為準。想確認總共多少錢，LINE 傳照片和想要的款式給我們。
